# 羽刃 · 夜场单打

为横屏 iPhone 和 iPad 制作的离线 3D 羽毛球单打游戏。靠一记高远球把对手调往底线，再试试把下一拍吊到网前。支持 iOS 16 及以上。

## 在 iPhone 或模拟器上运行

1. 在装有 Xcode 16.4 或兼容版本的 Mac 上打开 `Shuttle.xcodeproj`，选择共享方案 **Shuttle**。
2. 选择一台 iPhone 模拟器，按 ⌘R 进入主场。所有游戏资源均在工程内。
3. 真机运行时，在签名设置中选择自己的开发团队并使用可用的 Bundle Identifier，然后选择已连接的设备运行。

## 查看美术资产

`Preview/Featherblade-Court.jpg` 展示实际球馆和两名球员同场的离线渲染，`Preview/athletes.jpg` 展示球衣、鞋和线床的近景。`Preview/Athletes.usdz` 可用 iPhone「文件」中的快速查看旋转检查两名球员。游戏中的运动与光照由 SceneKit 实时计算。

## 第一局

点「进入球场」和「我方发球」开始。靠近镜头的是你。发球时比分为偶数从右区发，奇数从左区发。

| 操作 | 球场上的效果 |
| --- | --- |
| 自动步法 | 根据来球奔向合适击球点，回球后回位。 |
| 左下方向盘 | 手动调整位置，上推向网前、下拉退到底线。 |
| 点高远、吊球、扣杀 | 按键高亮时可以击球，稍早出手会短暂保留输入。低点击扣杀会改打解围球。 |
| 沿击球键左右滑动后松手 | 选择出球方向，滑动越远落点越靠边。轻点默认打向中路。 |
| 暂停 | 继续当前比分或返回主场。切到后台时比赛自动暂停。 |

短局采用每球得分制。先到 11 分且领先 2 分获胜，14 平后一球决胜。主场会记住个人最长回合。

## 实现与验证

- SwiftUI 房间与比赛界面，SceneKit 三维场馆，两套关节动画角色。网格包含运动服拼片、鞋底、拍框和独立拍线。短尾迹与地面落点提示帮助在远景中判断球路。
- 物理使用米、秒和固定的重力加速度。中点积分单步最长为 1/180 秒，逐段检查触网和落地。AI 从预测轨迹中选择能赶到的击球点，并根据对手位置选择前后场和左右线路。
- 游戏内音效本地合成，关键触球配合触觉反馈。球馆纹理与网格的再生成脚本位于 `ArtSource`。现有资源可直接用于构建。
- Swift 6.1.3 的 Linux 回归测试覆盖了 640 条击球轨迹、触网和界线、终端速度、接球预测及 30/59/120 Hz 下的落点一致性。另以渲染替身驱动实际对局逻辑完成 200 场短局，检查换发、封顶、暂停与重开。
- 当前交付经过 Swift 语法及 Xcode 工程结构检查。Apple SDK 构建、UI 测试、真机帧率与触控手感仍待 macOS 和 iPhone 环境验证。预览图使用工程网格离线渲染。

工程根目录下可独立执行物理回归测试。

```sh
swiftc -O Shuttle/BadmintonPhysics.swift Tests/Physics/main.swift -o /tmp/featherblade-physics
/tmp/featherblade-physics
```

在 Xcode 使用 ⌘U 运行原生测试。附带的 GitHub Actions 工作流在 macOS、Xcode 16.4 和 iPhone 16 模拟器上运行测试，并保留 xcresult 及测试截图。
